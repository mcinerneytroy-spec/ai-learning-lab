# Fictional investigation reports

These packages were generated by the full local analyzer against the bundled
synthetic inputs. They contain no live provider/company evidence. Actual UTC
analysis times differ from the fixed fictional event and approval dates.

ELEVATED recommends escalation for validation. ROUTINE recommends human review
with supporting context. Neither confirms compromise or safety; incident verdict
and analyst disposition remain UNCONFIRMED/PENDING. FAILED means the analysis
did not complete, not that an environment passed or failed a security control.

Source bytes are retained as Base64 in JSON. Base64 is encoding, not encryption
or anonymization. The supplied fingerprints do not establish tamper resistance.
The default demo analyst label is self-declared. Review the
[finished-project guide](../docs/FINISHED_PROJECT_GUIDE.md) for code and evidence details.
