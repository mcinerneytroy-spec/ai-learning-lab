# Fictional example reports

These examples were generated by the real local HTTP server and collector
against the two fictional snapshots. They are demonstration outputs, not company
data, proof of company controls, or accepted audit evidence. They use the collector
label `portfolio-demo`, which is self-declared.

- [Day 1 evidence](day-1/evidence.json) and [CSV report](day-1/controls.csv):
  MFA gaps, an administrator baseline, and a laptop missing EDR.
- [Day 2 evidence](day-2/evidence.json) and [CSV report](day-2/controls.csv):
  Blair's MFA improvement, Casey's grant to Blair, and the VM's stale check-in.

Collection timestamps are the actual example-generation times. Source observation
times and grant times are fixed fictional dates. Raw bodies contain only the
fictional source records; Base64 is not anonymization or encryption.

Routine collections go to Git-ignored `outputs/`. These curated copies are
intended to be included in GitHub. See [the evidence guide](../docs/EVIDENCE.md)
for field meanings and limitations.
